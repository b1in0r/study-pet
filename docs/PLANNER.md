# 网页填写学习计划

在仓库根目录双击 **打开计划管理.cmd**，或在终端运行：

```powershell
python -m studypet.web
```

然后打开 [本地计划管理](http://127.0.0.1:8765)。网页服务只监听本机，使用 Python 标准库，
不需要安装前端框架或登录账号。双击入口会在后台启动服务；重复打开会复用已有服务。
需要 Python 3.11+；本机开发环境存在 `.local/hardware-venv` 时会优先使用它。

## 日常使用

1. 在输入框填写计划，选择日期与时间，点击“添加计划”。
2. 完成后勾选复选框；取消勾选可以恢复待完成。
3. “修改”可调整内容、日期和时间；“删除”会先显示确认窗口。
4. 左侧日历可切换日期；“全部 / 待完成 / 已完成”用于筛选当天清单。

日期和时间使用北京时间。网页、任务命令行和桌历桥接共用 `.local/studypet.sqlite3`，
因此无需导出或复制计划。网页显示所选日期的全部任务，实体桌历显示当天前三项。

右侧“小屏预览”可查看最近生成的学习计划页或 Codex 页，切换预览不会切换设备的实际页面；
设备仍使用侧边 KEY 翻页。屏幕桥接运行时，保存的内容约 30 秒内同步到设备。
如果修改了其他日期的计划，实体屏幕会在对应日期显示它。

## 同步状态

“桌历同步正常”来自桥接程序成功发送并收到设备确认后的状态记录。
桥接中断、设备未连接或成功记录超过 90 秒时，网页显示“等待桌历同步”，计划仍可保存。
网页不负责自动启动屏幕桥接；启动方式见[屏幕说明](SCREEN.md)。

网页程序与桥接程序均未设置系统开机自启动。前台命令运行时可用 Ctrl+C 退出。
后台服务的日志和进程编号保存在 `.local/planner-web.log`、`.local/planner-web.pid`。
