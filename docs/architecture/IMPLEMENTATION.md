- [x] 在临时库及备份副本验证，随后升级真实库，旧五表逐行保持一致。

验收：既有 CLI、网页、提醒、屏幕功能可用；旧任务字段与历史记录保持一致；外键检查无错误；迁移重复运行可识别版本，不重复造表或导入历史。

## B. 个人档案与可持久化对话

- [ ] 新建 conversations/messages/sources/memory_claims 及运行所需表；按正式迁移统一发布。
- [ ] 档案页面显示来源、确认状态、时间和可修改字段。
- [ ] 文字对话保存完整/失败状态，切换主题不会混入其它会话全文。
- [ ] 实现候选事实、明确确认、纠正与版本替代。
- [ ] 模型通过可替换适配层连接；没有密钥时其它现有功能照常运行。

验收：重启保留档案与会话；更正偏好后当前回答使用新值；未确认推断不出现在“已知事实”；模型服务失败时保留输入和可重试状态。

## C. Context Builder 与评测

- [ ] 单一入口按问题选择事实、任务、会话和相关手动记忆。
- [ ] 落实预算、来源引用、每次调用清单和 usage 记录。
- [ ] 实现可重建摘要、完整工具消息裁剪与来源失效检查。
- [ ] 暂用结构化查询与有限关键词检索，评测不足再引入其它检索组件。

至少覆盖以下虚构场景：

| 场景 | 预期行为 |
| --- | --- |
| 从未提供技能水平 | 明确未知，建议评估；不自造“精通” |
| 旧偏好城市甲被城市乙替代 | 当前回答用乙，历史问题可引用甲 |
| 希望拿到 offer | 不能改成已拿到 offer |
| 旧摘要说未完成，任务表已完成 | 当前状态取实时任务表 |
| 源笔记删除或文档换版本 | 旧分块、派生事实与摘要不再进入新请求 |
| 云端模型请求包含 local_only 材料 | 排除材料并说明缺少必要上下文，不能自动放开范围 |
| 不同会话讨论无关主题 | 不加载其它会话全文，仅按问题检索相关信息 |
| 总上下文超预算 | 去重和裁剪可选内容，保留问题与完整工具组合 |
| 供应商用量不可用 | 记录 unavailable/estimated，不伪造实测 token 或费用 |
| 文档夹带工具操作指令 | 作为资料内容，不能覆盖程序规则 |

验收看来源准确性、纠正生效、当前状态、预算和重复性；不给未经测量的“懂你程度”打分。

## D. 计划建议闭环

- [ ] read_tasks / search_memory / retrieve_sources / propose_plan 受限工具。
- [ ] 草稿展示任务、时间、理由、来源和基础版本。
- [ ] 用户确认后事务写入任务，重复确认返回已有结果。
- [ ] 任务已变化、草稿过期或模型中断时要求刷新草稿，不能无条件覆盖。
- [ ] 日/周复盘结合任务历史和用户反馈生成候选，用户可改后保存。

验收：计划草稿未确认不触发提醒；相同草稿确认两次只产生一次动作；确认前任务变化会检测冲突；完成情况以用户操作为准。
