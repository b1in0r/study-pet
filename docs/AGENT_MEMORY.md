# 桌宠记忆与任务提醒

在[本地计划页面](http://127.0.0.1:8765)填写计划后，后台每 5 秒检查一次。
到点会生成网页提醒，并向 Windows 提交通知。点击通知区域里的 StudyPet 图标或通知可打开计划页。
这是第一版 Agent 的数据与执行基础：当前按明确计划执行规则，尚未接入大模型对话、自动拆解目标或自主判断学习状态。

## 日常操作

- **记忆本**：手动保存长期目标、学习偏好、复盘和随手记。当前用于保存和查阅；尚不会据此自动生成计划。
- **历史记录**：查看最近 100 条任务变化与提醒处理事件；数据库保留完整记录。
- **完成**：标记任务完成并撤下提醒。完成情况以用户操作为准。
- **10 分钟后提醒**：把任务时间调整为当前时间的 10 分钟后，到时生成新的提醒。
- **知道了**：确认本次提醒，不改变任务完成状态，也不会重复提醒这次时间点。
- **暂停提醒**：暂停产生和发送新提醒，已有网页提醒仍可处理。点击“继续提醒”恢复。
- **测试电脑通知**：发送一条独立的测试通知，不会创建学习任务。

网页提醒会保留到处理为止。电脑通知采用 Windows 原生通知区域消息，不需要浏览器通知权限。
系统的勿扰模式和通知设置可能影响显示。“已提交 Windows”表示系统接口接受请求，不保证用户已经看到。

## 运行条件

双击根目录的 **打开计划管理.cmd** 会在后台启动网页及提醒服务。
关闭浏览器标签后，服务仍会检查计划；退出后台 Python 服务、关机或休眠期间不能提醒。
目前没有设置开机自启动，重启电脑后需要再次打开入口。

服务启动或恢复后，只补查北京时间当天已经到点且未完成的计划，避免集中弹出之前几天的旧任务。
同一任务、同一时间点只生成一条提醒，重启后仍会去重。调整时间会取消旧提醒；改回已经提醒过的相同时间点不会再次弹出。
电脑通知调用失败最多尝试 3 次，重试间隔至少 60 秒；网页提醒仍可处理。
电脑通知暂不可用时，页面会提示。程序不会把没有确认完成的任务自动标为完成。

命令行运行：

```powershell
python -m studypet.web
# 仅运行管理页面，不启用提醒引擎
python -m studypet.web --no-agent
```

## 数据存在哪里

全部保存在本机 **`.local/studypet.sqlite3`**，网页、命令行和实体屏幕共用它，不需要另装数据库服务。

| 表 | 内容 |
| --- | --- |
| tasks | 计划、状态、创建/更新时间、完成时间、移除时间和修订号 |
| task_events | 任务变化前后快照、事件时间、提醒处理记录 |
| reminders | 到点提醒、确认状态、桌面发送状态与重试次数 |
| memories | 用户手动填写的目标、偏好、复盘与笔记 |
| agent_settings | 是否启用提醒和电脑通知 |

每次任务变化与对应历史在同一个数据库事务里保存。重复勾选完成不会覆盖首次完成时间。
已有旧库会自动升级并记录启用时的任务快照；旧记录没有的创建、完成时间保持未知，不补造历史。

**删除计划**会从日常清单移除，但保留计划历史，供回顾使用。
**删除记忆**会从记忆表移除正文，事件中只记录记忆编号，不复制正文。此操作不清除你另行保存的数据库备份。

`.local/` 已被 Git 忽略；个人计划、记忆、数据库备份不上传 GitHub，也没有发送给模型或外部服务。
本地数据尚未加密。备份时停止网页和屏幕桥接后复制数据库，或使用 SQLite backup 接口；不要把个人数据库提交到仓库。

本机升级前已用 SQLite backup 接口保存原库，位于 `.local/hardware-backups/`。
回退旧版程序前应先停止服务并恢复对应备份；恢复旧备份会丢失备份之后的修改，请先备份当前库。
