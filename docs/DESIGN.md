# 设计约定

## 使用方式

首版面向 Windows：电脑运行 Agent，硬件显示状态并接收交互。先接电脑，暂不要求关机后独立运行。关机或休眠时不能持续提醒。

## 角色与任务

后续模型可以提出学习计划；用户确认后才写入任务库。当前计划由用户在网页或 CLI 填写，完成情况依靠使用者确认，不声称能够判断真实学习状态。支持延期、确认收到和暂停提醒；安静时段尚待实现。

模型负责理解和建议，程序负责保存与执行。提醒时间保存在数据库，由确定性的调度机制检查，不让模型自行等待或计算后台计时。

当前网页已提供计划编辑、目标与偏好记忆本、历史查看，以及 Windows 通知和网页提醒。CLI 与屏幕桥接共用 SQLite；尚未接入模型工具调用，记忆本内容不会自动触发计划。

## 资讯

优先使用官方发布、论文和开源项目原始来源。保留标题、原文 URL、发布日期、抓取时间与来源；区分原文事实与模型解释。资料不足时说明不足。优先保存链接及短摘要，避免把完整文章复制到仓库。

## 音频

ESP32-S3-RLCD-4.2 已实现 USB 扬声器与串口屏幕数据共用一根 USB 线。按用户当前选择，不启用 USB 麦克风，提醒采用电脑通知与网页，不播放语音。

后续如增加对话语音，再设计收音指示、停止录音与录音保存规则。

## 数据与模型

任务、历史、提醒状态与手动记忆仅保存在本机 `.local/`，不提交 Git。任务从清单移除后保留历史；记忆删除时移除正文，不把正文复制到历史事件。升级旧库只保存当前快照，不补造过去时间。详细数据约定见 [记忆与提醒](AGENT_MEMORY.md)。未来使用云端模型时，需在配置说明中明确哪些文字或音频会发送到服务商，提供调用费用控制与可替换的适配层。

## 首版评测

当前关注任务保存与重启恢复、旧库迁移、提醒去重及延期、历史保留、屏幕同步和音频设备拔插恢复。模型与资讯接入后增加引用质量和响应时间检查。不用未经测量的准确率和延迟作为项目宣传。
