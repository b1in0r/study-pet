## 下一阶段：让模型能读取计划并提出建议

目录、数据库与上下文按 [个人助理架构规划](architecture/README.md) 分阶段落地；先统一存储，再接档案与对话。

- [ ] 可替换的模型适配层，提供密钥配置和费用上限。
- [ ] 文字对话界面，读取今日计划、近期历史和用户选择的记忆。
- [ ] 工具调用：查询计划、提出新计划或调整建议，用户确认后再执行写入。
- [ ] 晚间复盘草稿，用户可修改后存入记忆本。
- [ ] 记忆检索与来源展示，区分用户确认的信息和模型推测。

验收：用户询问“今天还要做什么”时，模型基于真实数据库回答；建议的任务只有确认后才保存；没有模型服务也能继续管理计划和提醒。

## 候选方向

本地模型、跨平台、简单外壳与独立运行。动作机构暂不在当前需求范围内，按实际使用反馈安排。
