# 开发路线

## 已实现

- [x] 无第三方运行依赖的 Python 命令行入口。
- [x] SQLite 保存任务；新增、列出、完成任务。
- [x] 按带时区的截止时间查询待处理任务。
- [x] MIT 许可证、贡献说明、首版设计约定。

## 第一阶段：电脑上的可用闭环

- [ ] 简单桌宠界面，显示空闲、听取、思考、说话、提醒状态。
- [ ] 按键语音输入、语音输出与文字备选输入。
- [ ] 模型适配接口与配置示例，明确离线和联网能力。
- [ ] 资讯来源采集、去重、带引用的简报及追问。
- [ ] 学习目标与偏好管理，计划确认后写入任务库。
- [ ] 后台提醒、延期、跳过与简短复盘。

验收：使用者可以听一条带来源的资讯、追问、确认一个学习任务，在约定时间收到提醒并标记完成。重启程序后任务仍存在。

## 第二阶段：接入实体屏幕

- [ ] 选定一款无需焊接的屏幕开发板，记录型号与硬件版本。
- [ ] 电脑与开发板的通信协议、状态同步、断线重连。
- [ ] 表情动画、按键输入、当前任务摘要。
- [ ] 新手刷写指南与实测视频。

验收：电脑端状态能驱动屏幕，拔插后恢复通信；失败不会影响电脑正常音频播放。

## 第三阶段：音频与外壳集成

- [ ] 现成音响和麦克风的接入、设备选择、音量与暂停收音。
- [ ] 区分聊天、会议和普通音响模式。
- [ ] 回声、误唤醒、响应延迟的实际测量。
- [ ] 简单外壳与模块安装说明。
- [ ] 评估统一 USB 接口或自定义 USB 音频固件的必要性。

## 后续候选

动作与触摸、本地模型、跨平台支持、独立运行硬件。根据实际使用反馈决定顺序。
